自動本機儲存中 (LocalStorage)

你在這個畫面上新增或修改的任何行程，都會自動儲存在你目前的手機或電腦瀏覽器裡，就算沒有網路也能隨時打開查看！

📤 方式一：傳送行程代碼給旅伴（或跨裝置同步）

如果你在電腦排好行程，想傳給手機或旅伴：點選下方「複製行程資料代碼」，透過 LINE 傳給對方，對方打開網址後點選「貼上並匯入」即可瞬間同步！

💡 方式二：如何把排好的行程永久寫入 GitHub Pages？

如果你想讓所有打開你 GitHub 網址的人，不用匯入就能直接看到最新行程：只要點擊上方「複製目前行程代碼」，打開你 GitHub 上的 index.html，找到程式碼下方的 const DEFAULT_TRIP_DATA = ...，把整段替換成你複製的內容即可！
